# Geometry atlas

219 geometry problem statements and representative drawing previews, ordered newest first (2025 to 1965). Responsive on phones and desktops, with search, year filtering and an enlarged drawing view.

Drawings await human verification and are illustrations, not proofs. Some transcribed mathematical symbols may need checking against the original statements.

This public preview contains no review controls or personal review notes.

Open https://modigmd.github.io/geometry-atlas/
